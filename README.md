#Project Title
## Idea
This project analyzes social media behavior using machine learning and time-series modeling to predict stress levels.  
It identifies digital saturation points and gives personalized preventive recommendations to reduce psychological risks.

## Tools
- Python
- Pandas
- Scikit-learn
- TensorFlow
- Matplotlib
- React
- GitHub

## Steps
1. Collect social media behavior data.
2. Clean and prepare the data using Pandas.
3. Train a machine learning model to predict stress levels.
4. Analyze behavior over time using time-series modeling.
5. Display results and recommendations in a simple user interface.

## Results
- Predicted stress levels based on user behavior.
- Identified digital saturation points.
- Provided personalized recommendations.
- Displayed results using graphs and screenshots.
